# Landing page (proposal)

Static marketing page for the AyosPapel proposal. Plain HTML, CSS, and an
ES-module Three.js scene loaded from jsDelivr (three@0.169.0). No build step.

- Preview locally: `npx serve landing -l 5180`
- Deploy: `vercel deploy --prod` from this folder (Vercel project `ayospapel`)

All batches, names, and dates shown are fictional sample data. The page is
marked `noindex` while it is a proposal.
